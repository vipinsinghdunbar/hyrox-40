# REQUEST TEMPLATE

Copy this into the chat for every request. Short answers are fine. If a field is unknown, write "unknown" and the factory will state an assumption.

- Type: feature, bug, UX problem, idea or change.
- Problem: what is wrong or missing, in plain language.
- Who is affected: which user or situation.
- Where: screen, flow or component, if known.
- Success looks like: one observable outcome. A number is better than an adjective. Example: onboarding takes 4 steps or fewer instead of 7.
- Out of scope: what must not change.
- Device or context: iPhone model, browser, logged in or out.
- Urgency: now, this week or someday.
